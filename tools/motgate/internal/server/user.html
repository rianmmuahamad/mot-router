Pertanyaan yang sering muncul
Beberapa hal yang perlu kamu tahu sebelum memulai.
Apakah ada batas token?
Akses akun berlaku berdasarkan waktu. Selama akun aktif, token tidak dibatasi oleh paket akses Arbyte. Ketersediaan model tetap bergantung pada layanan upstream.
Bagaimana kalau masa aktif habis?
Request baru tidak bisa diproses saat akses sudah kedaluwarsa. Perpanjang akses melalui halaman paket, kemudian gunakan API key sesuai petunjuk akunmu.
Mengapa token terhitung nol?
Token dihitung dari laporan usage upstream. Jika model tidak mengirim jumlah token, dashboard menampilkan nol; jumlah request tetap tercatat.
Bagaimana menjaga API key tetap aman?
Gunakan environment variable pada aplikasi. Hindari menyimpan key di repository publik, screenshot, atau source code yang dibagikan.
