Pertanyaan umum

Yang sering ditanyakan.

Apakah ada batas request?+
Tidak ada batas jumlah request selama akses aktif. Batas teknis penggunaan wajar tetap diterapkan agar layanan stabil untuk semua pengguna, termasuk pembatasan request bersamaan.
Bagaimana cara menggunakannya?+
Kamu mendapatkan satu API key dan satu base URL. Ganti base URL pada SDK OpenAI atau Anthropic yang kamu gunakan, masukkan API key, lalu jalankan. Contoh lengkap tersedia di bagian Quickstart.
Apakah masa akses bisa diperpanjang?+
Bisa. Perpanjangan akan ditambahkan ke sisa waktu yang masih ada, jadi durasinya tidak dimulai ulang dari nol.
Di mana saya melihat penggunaan?+
Buka https://arbyte.coddx.store/u/kunci_kamu. Halaman tersebut menampilkan sisa waktu akses dan jumlah request yang sudah digunakan.
